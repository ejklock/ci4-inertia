# Security policy

## Supported versions

| Version | Supported |
| --- | --- |
| 3.x | Yes |
| 0.2.x | Security fixes only |
| 0.1.x | No |

Only the latest release of a supported series receives fixes.

## Reporting a vulnerability

Do not open a public issue or pull request for a vulnerability. Report it privately through GitHub:

<https://github.com/ejklock/ci4-inertia/security/advisories/new>

Please include:

- the affected package version, PHP version and CodeIgniter version;
- a description of the issue and its impact;
- steps or a minimal code sample that reproduce it;
- any fix or mitigation you already know of.

## What to expect

The maintainer reads every report, replies to confirm it or to ask for details, and works on a fix in the private advisory. No fixed response time is promised; this is a volunteer project. When a fix ships, the advisory is published and credits you if you wish.
